📦 Firestore 設計

courses / {courseId} / { name, width, height, cells: ["RRR...", ...], objects: [{type,x,y,rotation}], start:{x,y}, goal:{x,y}, created, updated } characters / {characterId} / { name, imageUrl } ※ game.htmlではURL直指定も可

操作: PCはマウス/ホイール/ドラッグ、スマホはタッチ・ピンチ対応。エディターは右ドラッグ/ Space+ドラッグでスクロール。
必須チェック: 道路1マス以上＆ゴール1マス以上必須（ゴールはライン・複数可）。スタートは線で広く取れ、向き（8方向）を設定可。スタート/ゴールは道路上のみ配置可。スタート未配置は警告のみで保存可。
走行: フリー走行（ゴールへの自動補正なし）。自動アクセル／手動を選択可。スタートから離れてゴール線に触れたらGOAL。
画質: 👾ドット絵（レトロ2D）／🧱ローポリ／✨高ディティールの3段階変換。道路は⬛カクカク／〰なめらか（曲線自動生成）を選択可。
