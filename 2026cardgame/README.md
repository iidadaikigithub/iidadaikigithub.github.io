# 2026 CARD DUEL

ブラウザだけで遊べる、1台交代（ホットシート）式の対戦カードゲームです。
キャラクター・カード・ゲーム設定は **Firestore** に保存します。

---

## ファイル構成

| ファイル | 役割 |
|---|---|
| `player.html` | キャラクター作成（通常・攻撃・被弾の3画像） |
| `cardsakusei.html` | カード作成（名前・画像・攻撃・防御・命中率・特殊能力） |
| `settei.html` | ゲーム設定（人数・デッキ・体力・ドロー枚数・使用カード） |
| `index.html` | ゲーム画面（キャラ選択 → 対戦） |
| `common.js` | Firebase 初期化・画像圧縮・効果音・共通処理 |
| `game.js` / `game.css` | ゲーム本体のロジック・演出 |
| `style.css` | 共通デザイン |
| `firestore.rules` | Firestore のルール（下記参照） |

## 最初にやること（重要）

Firestore のセキュリティルールが「拒否」になっていると、保存も読み込みもできません
（`Missing or insufficient permissions` と表示されます）。

1. [Firebase コンソール](https://console.firebase.google.com/) で `cardgame-8bf6c` を開く
2. 「Firestore Database」→「ルール」タブ
3. `firestore.rules` の内容を貼り付けて「公開」

```js
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /characters/{docId} { allow read, write: if true; }
    match /cards/{docId}      { allow read, write: if true; }
    match /settings/{docId}   { allow read, write: if true; }
  }
}
```

> これはテスト用（誰でも読み書き可能）です。公開する場合は Firebase Authentication で
> ユーザー制限をかけてください。

### 開き方

フォルダ内の `index.html` をダブルクリックするか、`player.html` から順に開いてください。
（画像は Firestore に Base64 で保存されるため、Storage の設定は不要です。
アップロード時に WebP へ自動圧縮します。）

## 使い方

### 1. `player.html` — キャラクター作成

- キャラクター名を入力
- 「通常の画像」「攻撃した顔」「攻撃を受けた顔」を登録
  - **画像を選択**ボタン、または枠を選んで **Ctrl+V** で貼り付け
  - ドラッグ＆ドロップにも対応
- 「キャラクターを保存」

未登録の画像は通常画像で代用されます。登録済みキャラは一覧から編集・削除できます。

### 2. `cardsakusei.html` — カード作成

- カード名・画像
- 攻撃名 / 攻撃力（0〜99,999）
- 防御名 / 防御力（0〜99,999）
- 命中率（0〜100% / 初期値 85%）
- 特殊能力（10種類から1つ）
- 右側のプレビューで見た目を確認して保存

### 3. `settei.html` — ゲーム設定

- **何人で遊ぶか**: 1〜4人（1人＝ソロ練習、2〜4人＝対戦）
- **カードの束**: 1〜100枚。有効カードからランダムに作成し、足りない分は自動コピー
- **体力**: 0〜100,000
- **一度に引く数**: 1〜5枚
- **使用するカード**: カード一覧のスイッチをオフにするとデッキに出ません
- 「設定を保存」

### 4. `index.html` — ゲーム

- プレイヤーごとにキャラクターを選択（同じキャラも可）
- 「ゲーム開始」
- 自分のターンに次の3つから1つ選ぶ

## ゲームルール

### 勝利条件

最後までライフが残っているプレイヤーの勝ち。ライフが0になったら脱落です。

### ターンの流れ（1ターンに1つ）

1. **引く**
   - 束から設定枚数（1〜5枚）を1枚ずつ引きます。
   - 前回引いたカードはここで捨てます。
   - 引いたカードの攻撃力で **相手全員** を攻撃します（相手ごとに命中率判定）。
   - 引いたカードの防御力が、次の自分のターンまでの防御値になります。
2. **防御**
   - 前回引いたカードの防御力を **2倍** にして、次の相手の攻撃に備えます。
3. **特殊効果**
   - 前回引いたカードの特殊能力を発動します。効果は次回以降に反映されます。

引いたカードは「前回のカード」として画面右下に表示されます。
自分のターンが来ると防御値はリセットされます（防御は次の自分のターンまで）。

**カード1枚につき、防御か特殊効果は「どちらか1回だけ」使えます。**
どちらかを使うと、そのカードは「使用済み」になり、次のターンは必ず「引く」で新しいカードを引いてください。

### ダメージと防御

- 攻撃は相手全員に同時に飛びます。
- 相手の防御値が攻撃を軽減します。
  - **赤い数字** … ダメージ
  - **青い数字** … 防御（軽減した量）
- 防御値が攻撃力を上回ると、あふれた分だけ **攻撃した側に反撃ダメージ** を与えます。
- 防御値は攻撃を受け止めると消費されます。
- 防御と攻撃がぶつかると相殺演出が入ります。

### 命中率

- カードごとに攻撃の命中率を設定できます（0〜100% / 初期値 85%）。
- 攻撃は **相手ごと** に命中判定します。外れるとダメージなしで、**相手の防御値は消費されず、反撃も発生しません**。
- 命中率アップ / ダウンは **±20ポイント**（補正後は 5〜100% に丸め）。
- 補正は「次の自分の攻撃」にのみ有効で、攻撃が終わると解除されます。1ターンに複数枚引いた場合はそのターンの全攻撃に適用されます。
- 命中率の記録がない古いカードは 85% として扱います。

### 特殊能力

| 能力 | 効果 |
|---|---|
| 効果なし | 何も起きない |
| 一回休み攻撃力 | 相手の次の攻撃を無効化 |
| 次のターン自分の攻撃力2倍 | 自分の次の攻撃が2倍 |
| 次のターン自分の防御力2倍 | 自分の次の防御が2倍 |
| 次のターン相手の攻撃力半分 | 相手の次の攻撃が半分 |
| 次のターン相手の防御力半分 | 相手の次の防御が半分 |
| 自分を30%回復 | 最大HPの30%を回復 |
| 自分を50%回復 | 最大HPの50%を回復 |
| 命中率アップ | 自分の次の攻撃の命中率 +20% |
| 命中率ダウン | 相手の次の攻撃の命中率 -20% |

特殊効果は1枚につき1回まで使えます（防御を使ったカードは特殊効果も使えません）。新しいカードを引くとリセットされます。

### 演出・効果音

- カードは束から回転しながら引かれます。
- 攻撃時は攻撃した顔に切り替わり、斬撃が相手に飛びます。
- 攻撃を受けた相手は被弾顔で揺れ、大きな赤いダメージ数字が出ます。
- 防御は青い数字とシールド演出。反撃はカウンター演出。
- ドロー / 攻撃 / 防御 / 回復 / 勝敗などの効果音は WebAudio で合成しています（音声ファイル不要）。
- 右上の 🔊 ボタンでミュート切替。

### キーボード操作

- `1` … 引く
- `2` … 防御
- `3` … 特殊効果

## データ構造（Firestore）

```
characters/{id}
  name: string
  images: { normal, attack, hurt }   // WebP の dataURL
  createdAt / updatedAt: timestamp

cards/{id}
  name, image,
  atkName, atk, defName, def,
  acc: 0-100                          // 攻撃の命中率（未設定は 85 扱い）
  special: 'none' | 'rest' | 'atk2x' | 'def2x' | 'enemyAtkHalf' | 'enemyDefHalf' | 'heal30' | 'heal50' | 'accUp' | 'accDown'
  createdAt / updatedAt: timestamp

settings/game
  playerCount: 1-4
  deckSize: 1-100
  hp: 0-100000
  drawCount: 1-5
  excluded: string[]   // 使用しないカードID
```

> Firestore の1ドキュメント上限は 1 MiB です。画像は保存前に長辺 512px 前後の WebP に
> 圧縮していますが、3枚とも大きい写真の場合は保存に失敗することがあります。
> その場合は画像を小さめにするか、カード画像を減らしてください。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「Missing or insufficient permissions」 | Firestore のルールを `firestore.rules` の内容に変更 |
| 保存ボタンが押せない | Firebase の初期化失敗。CDN に接続できるか確認 |
| 画像が表示されない | 画像未登録なら通常画像が使われます。通常画像は必須 |
| 効果音が出ない | 最初に画面をクリック（ブラウザの自動再生制限）。🔊 がオンか確認 |
| サンプルデータで起動する | Firestore が空、または接続失敗。登録すると反映されます |
